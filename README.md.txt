# RELE WIFI

## Descripción
Este proyecto consiste en un relé controlado de manera inalámbrica utilizando un módulo ESP32. El ESP32 se conecta a una red Wi-Fi y permite controlar el relé de forma remota a través de una aplicación móvil o un sistema web.
